# Test image sources

| File | Class | Source |
|---|---|---|
| `cat.jpg` | cat | "Chelsea the cat", sample image distributed with [scikit-image](https://scikit-image.org/) (`skimage.data.chelsea`) |
| `car.jpg` | automobile | ImageNet sample image (class *convertible*), from [EliSchwartz/imagenet-sample-images](https://github.com/EliSchwartz/imagenet-sample-images) |
| `webots_camera.png` | dog | Frame from the e-puck camera (52 × 39 pixels) in Webots, world `worlds/cnn_camera_test.wbt`, saved by `controllers/cnn_camera_classifier` |

The photos are used only to test the classifier in this academic project.
